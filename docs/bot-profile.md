# Bot profile texts

The public texts for the AgentOS bot (`@tryagentos_bot`) and a landing page.
They follow the README: *a work computer for your agents — Security & Privacy
first, any models, host it even on your own box.*

Telegram limits: the short description (shown on the bot's profile and in
shares) is 120 characters at most; the description (shown in an empty chat)
is 512 characters at most. Set them in @BotFather (`/setabouttext`,
`/setdescription`) or with the Bot API (`setMyShortDescription`,
`setMyDescription`).

## Short description (about)

```
A work computer for your agents. Security & Privacy first, any models, even on your own box.
```

## Description

```
AgentOS is a work computer for your agents: a machine of their own with a Telegram bot, scheduled routines and a Mini App.

• Security & Privacy first: your data and keys stay on your machine.
• Any models: Anthropic, OpenAI and others, including local ones.
• Host it anywhere: a managed machine, your own VM or your own hardware.

Message me like a person. I do the work and report back here.
```
